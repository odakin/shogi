# shogi

単一 HTML ファイルの将棋棋譜ビューア。`index.html` をブラウザで開くだけ。

[English version](README.md)

## Why this exists

ある対局を 1 つだけ表示するビューア。ビルド・依存・サーバ不要。第 84 期名人戦第 2 局（▲藤井聡太 − △糸谷哲郎、89 手）をプリロード。

## クイック例

```sh
python3 -m http.server 8000
# http://localhost:8000/ をブラウザで開く
```

`←` / `→` で進む・戻る、`Space` で自動再生、棋譜リストの手をクリックでジャンプ。

## どこに何があるか

- `index.html` — 本体一式（HTML / CSS / JS / 棋譜データ、約 680 行）
- `CLAUDE.md` — リポ概要・構造・データ形式
- `DESIGN.md` — 設計判断（単一ファイル方針、棋譜文字列リゾルバ）

## 補足

- 棋譜は `index.html` 内の `KIFU` 定数として埋め込み済。パーサは `▲`/`△`（先後）、`同`、`成`/`馬`/`龍`/`と`、`打`、`(封)` を処理。`from`（移動元）は `reachableSquares()` で逆算
- パーサ・盤面リゾルバは Node で全 89 手リプレイ済 — **触らない**で、拡張は別ファイル分離で
